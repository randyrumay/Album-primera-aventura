# Nuestra Primera Aventura — álbum digital

Esta versión utiliza directamente las 7 páginas visuales proporcionadas para el álbum:

1. Portada
2. Primera página — 1 fotografía
3. Primera parada — 2 fotografías
4. Fotografías 01 — 2 fotografías
5. Fotografías 02 — 2 fotografías
6. Página para romper el ritmo — sin fotografía
7. Postales — 1 fotografía
8. Cierre — mensaje final

## Fotografías

Coloca las 8 fotos en `assets/photos/` como `01.jpg` a `08.jpg`.
Las posiciones ya están preparadas para los marcos de las páginas.

## Música

Coloca `the-door-teddy-swims.mp3` en `assets/audio/`.
La reproducción se inicia cuando se pulsa “ABRIR EL ÁLBUM”, respetando las políticas de autoplay de los navegadores.

## GitHub Pages

Sube el contenido de esta carpeta al directorio raíz del repositorio.
