# Nuestra Primera Aventura — versión basada en My Adventure Book

Esta versión usa las páginas visuales de la plantilla inicial como fondos y añade navegación para celular.

## Fotos
Coloca tus fotografías en `assets/photos/` con estos nombres:
`01.jpg` a `12.jpg`.

Si todavía no existen, las páginas muestran el diseño de la plantilla sin esas fotografías.

## Música
El archivo esperado es `assets/audio/the-door-teddy-swims.mp3`. No se incluye la grabación. Úsalo únicamente si tienes autorización para publicarla en GitHub Pages.

## GitHub Pages
Sube `index.html` y la carpeta `assets/` al repositorio. Activa GitHub Pages desde Settings → Pages → Deploy from a branch → main → /(root).
