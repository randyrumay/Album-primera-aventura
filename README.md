# Nuestra Primera Aventura — versión basada en My Adventure Book

Esta versión usa **las páginas visuales renderizadas de la plantilla original** como fondos del álbum, en lugar de intentar imitar su estética solamente con CSS.

## Estructura
- `index.html` — álbum completo.
- `style.css` — adaptación responsive y efectos.
- `script.js` — navegación, teclado, gestos táctiles y música.
- `assets/template/` — fondos derivados de las páginas de la plantilla.
- `assets/photos/01.jpg` a `12.jpg` — coloca aquí tus fotografías.
- `assets/audio/the-door-teddy-swims.mp3` — coloca aquí el archivo de audio únicamente si tienes los derechos o autorización para publicarlo.
- `assets/qr.png` — QR que apunta a la URL de GitHub Pages.

## Publicar en GitHub Pages
1. Sube **todo el contenido de esta carpeta** a la raíz del repositorio.
2. En GitHub: `Settings > Pages > Deploy from a branch > main > / (root)`.
3. La URL prevista es:
   `https://randyrumay.github.io/Album-primera-aventura/`
4. Agrega tus fotos con los nombres `01.jpg` ... `12.jpg`.

## Importante
La grabación comercial de **The Door — Teddy Swims** no está incluida. Si vas a publicar el álbum, usa el audio solo si cuentas con los derechos o autorización correspondientes.
