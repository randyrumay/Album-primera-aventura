# Nuestra primera aventura

Álbum fotográfico digital pensado para GitHub Pages.

## Estructura

- `index.html`
- `style.css`
- `script.js`
- `assets/photos/01.jpg` a `08.jpg`
- `assets/audio/the-door-teddy-swims.mp3`

## Publicación en GitHub Pages

1. Sube todos los archivos y carpetas manteniendo exactamente esta estructura.
2. En GitHub entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona `Deploy from a branch`.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda y espera la publicación.

## Fotos

Coloca tus fotos en `assets/photos/` con los nombres `01.jpg` hasta `08.jpg`.

## Música

El proyecto está preparado para `assets/audio/the-door-teddy-swims.mp3`.
El archivo de audio no se incluye. Usa la grabación únicamente si tienes los derechos o autorización necesarios para publicarla.

## Importante

No subas solamente `index.html`. Para que el diseño y la interacción funcionen debes subir también `style.css`, `script.js` y la carpeta `assets`.
